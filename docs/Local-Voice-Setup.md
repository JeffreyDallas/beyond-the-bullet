# Local faster-whisper and Kokoro setup

Beyond the Bullet remains text-only unless local voice mode is explicitly enabled. The backend speech adapters use local `faster-whisper` for speech-to-text and Kokoro for text-to-speech; they do not call a hosted speech API.

## Install

```bash
source .venv/bin/activate
pip install -r requirements-voice.txt
```

The optional packages can be large. Keep enough disk space and RAM for the models you select. The application does not download weights during import or startup; the first request that needs a model may download missing weights.

## Configure

```bash
export LOCAL_VOICE_MODE=true
export WHISPER_MODEL=small.en
export WHISPER_DEVICE=cpu
export WHISPER_COMPUTE_TYPE=int8
export KOKORO_VOICE=af_heart
export KOKORO_LANG_CODE=a
uvicorn backend.main:app --reload --port 8000
```

For an already downloaded Whisper model, set `WHISPER_MODEL_PATH` to its local directory. Otherwise `WHISPER_MODEL` is passed to faster-whisper and may resolve/download a named model on first use.

Verify configuration without loading either model:

```bash
curl http://127.0.0.1:8000/api/voice/status
```

The status response reports package availability and whether each model has been loaded. Models load only when their endpoint is called.

## Endpoints

- `POST /api/voice/transcribe` — multipart audio upload; returns transcript text and segment timings.
- `POST /api/voice/synthesize` — JSON `{"text":"..."}`; returns a WAV response generated by Kokoro.

The existing browser voice mode is a separate convenience UI path. It uses browser speech recognition and synthesis, automatically submits after a brief pause, recovers unexpected recognition endings when possible, and exposes a Voice debug panel under the transcript. These HTTP endpoints provide the local model boundary for server-side STT/TTS and the later real-time transport work described in the project plan.

## Tests and cost control

Unit and Playwright tests leave `LOCAL_VOICE_MODE` disabled and use the deterministic mock LLM. They do not download speech models, request microphone access, or spend hosted LLM tokens. Run a local voice smoke test manually only after installing the optional dependencies and explicitly enabling the mode.
